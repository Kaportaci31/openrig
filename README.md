## 👋 What is openrig?

openrig is a friendly tool that helps you build your own team of AI helpers on your computer. Think of it like having a bunch of smart assistants that can work together on projects - some write code, some review it, some keep track of everything. They never sleep, never take breaks, and they all work together to get things done faster.

Instead of switching between different AI coding tools manually, openrig lets you combine powerful tools like **Claude Code**, **Codex**, and **Pi** into one team. Each member gets a role, shares what they know, and takes ownership of specific tasks. It's like having a mini software company running right on your computer!

It uses a technology called "tmux" to manage multiple windows neatly, and it's built with TypeScript to be reliable and fast.

This guide will walk you through getting openrig up and running on your Windows computer. We promise - no programming knowledge needed!

## 🧑‍💻 Tips & Tricks

- **Start small**: Use just two agents on your first project. Get comfortable with how they communicate.
- **Use roles clearly**: Instead of saying "do stuff", tell an agent "You are the reviewer. Check every file for errors." Clear roles mean better results.
